# NightSquawk Tech

Managed IT and security services (MSP/MSSP). We automate our own operations and open-source the tooling.

## MCP Servers

Open-source [Model Context Protocol](https://modelcontextprotocol.io) servers for the platforms we run:

- [proxmox-mcp-server](https://github.com/NightSquawk/proxmox-mcp-server): Proxmox VE + Datacenter Manager, the full API behind six catalog tools
- [tacticalrmm-mcp-server](https://github.com/NightSquawk/tacticalrmm-mcp-server): TacticalRMM agents, checks, alerts, and audit logs
- [kimai-mcp-server](https://github.com/NightSquawk/kimai-mcp-server): Kimai time tracking with guarded writes
- [gohighlevel-mcp-server](https://github.com/NightSquawk/gohighlevel-mcp-server): GoHighLevel CRM, including the gaps the official MCP leaves open
- [invoiceninja-mcp-server](https://github.com/NightSquawk/invoiceninja-mcp-server): Invoice Ninja v5, all 379 endpoints with backed-up mutations
- [appfolio-mcp-server](https://github.com/NightSquawk/appfolio-mcp-server): AppFolio reports and Database API

Setup instructions and the full index live at [mcp-servers](https://github.com/NightSquawk/mcp-servers). More on the way.

All of it is AGPL-3.0: free for personal and open-source use, with commercial licenses and hosted versions available for organizations.
