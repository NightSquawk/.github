# NightSquawk Tech

Managed IT and security services (MSP/MSSP). We automate our own operations and open-source the tooling.

## MCP Servers

We publish [Model Context Protocol](https://modelcontextprotocol.io) servers for the platforms we run: Proxmox, TacticalRMM, Invoice Ninja, Kimai, AppFolio, GoHighLevel, and more.

Start at the **[mcp-servers](https://github.com/NightSquawk/mcp-servers)** index, or grab the shared runtime [`@nightsquawktech/mcp-core`](https://github.com/NightSquawk/mcp-core).

All of it is AGPL-3.0: free for personal and open-source use, with commercial licenses and hosted versions available for organizations.
